# REST API Data Ingestion Pipeline

## Overview
A Python-based data ingestion pipeline that extracts data from public REST APIs, processes JSON responses, and loads the data into a MySQL database.

## Architecture

REST API → Python (Requests) → Data Processing → MySQL

## Tech Stack
- Python
- REST APIs
- Requests
- MySQL
- SQL
- Git & GitHub

## Project Goals
- Extract data from public REST APIs.
- Handle JSON responses.
- Transform and validate data.
- Load data into MySQL.
- Implement error handling and logging.
- Automate data ingestion.

## Project Status
In Development

## How to Run

1. Clone the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Configure database credentials in `.env`.
4. Run the ingestion script.
